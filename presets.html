How to use them

Install in a minute

Phone

Lightroom mobile

Download the .dng file and open it in Lightroom. Tap the three dots, choose Create Preset, name it, and save. It now works on any photo.

Computer

Lightroom Classic or Lightroom

Download the .xmp file. In the Presets panel, click the plus or three-dot menu, choose Import Presets, and pick the file.
